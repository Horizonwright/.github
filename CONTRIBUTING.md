# Contributing to Horizonwright projects

1. **Open or pick an issue.** Every change starts with one. Atlas mirrors each issue into a post in the project's `#…-issues` forum on our Discord.
2. **Branch** from `main`: `feat/<issue>-short-name`, `fix/<issue>-…`, `chore/…`.
3. **Open a PR** with `Closes #<issue>` in the description (the template has it). PRs without a linked issue fail the **Atlas** check.
4. **Keep CI green.** Every push, review and CI result shows up in the issue's Discord post.
5. **Merge** once approved and green. Atlas closes the issue and locks its post.

Each repository's own `README.md` / `CLAUDE.md` covers setup, commands and architecture.
