# Horizonwright/.github

Organisation-wide defaults:

- `profile/README.md` — the org's public landing page
- `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` — default issue and PR templates for every repo without its own
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` — default community files
- `brand/` — mark (`logo.svg`, `logo-512.png`), profile banner (`banner.svg`, `banner-1280x400.png`), social preview (`social.svg`, `social-1280x640.png`). Mark: an H whose crossbar is the horizon line, running out to a terminal cursor. Colors: ink `#0B1016`, signal `#22D3C5` → `#67F0FF`, paper `#EEF2F6`.
